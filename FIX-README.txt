v3.7：在 v3.6 基础上只修复「一起听 / iMessage」内置气泡的尾巴颜色与气泡本体不一致问题。
根因：气泡本体使用 CSS 主题变量，但尾巴仍走单独的 PNG/SVG mask/image 渲染链；在手机 Quark 深色环境下，接收方尾巴会被渲染成比气泡更黑的独立层。
处理方式：这 5 个内置主题的发送/接收尾巴改为纯 CSS 形状，并与气泡本体共用 --xs-theme-sent-bg / --xs-theme-received-bg；不再使用尾巴图片或 mask。其他气泡主题不变。
继承：v3.6 的内层黑框修复、v3.5 的表情滚动/超时修复、v3.4 的主动表情在线判断全部保留。
